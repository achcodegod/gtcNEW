How it works

The short version

Pick a game and the launcher opens it in a new tab that looks like another website: it borrows that site's icon and a tab name you choose. Nothing is installed, and the game still runs from its original website.

Playing a game

  • Click a game once to select it (it gets a blue outline), then click it again to open it.
  • The search box filters the list by name. The list scrolls up and down with your mouse wheel.
  • To add a game, find the EXAMPLES list near the top of the code and copy one line. Change the name and the address (the link to the game's index.html). You can also add img with the address of a cover picture of your choice, which is used instead of the automatic one.
  • To add news, find the NEWS list just below it and copy one block. Give it a title, the text, and optionally an img address for a picture. Put the newest block at the top.

What happens when you open a game

  • A new tab is created and given the disguise: the icon of the disguise site and the tab name you chose.
  • That tab downloads the game's page as text. It tries the game's website directly first. If the site refuses and the public relay option is on, it retries through public relay services, one after another.
  • The page is then started inside a frame, set up so the game finds its files at its own website instead of looking in the wrong place. Inline scripts that check the page's address are pointed at the game's real address, which stops many games from crashing.
  • If a file the game asks for fails to download, the launcher races several alternatives (the original address, the game's folder, mirrors of the same file when one exists, then the relay services). It uses the first that answers, remembers which route worked so later files load faster, and gives each attempt 15 seconds.
  • Unity games get extra fixes: compressed .gz files are unpacked if they arrive still compressed, and .wasm files are labelled correctly.
  • Flash games (run by Ruffle) need the extra details their own script tag carries, such as which Flash file to play. The launcher keeps those details when it has to fetch a script another way. These games use a fixed-size player, so they stay smaller than the tab.
  • If the browser blocks cookies or saved data inside the frame, the game gets a temporary in-memory stand-in so it can still start. In that case its saves may not survive closing the tab.

Game covers

Each game's picture is looked up automatically by its name followed by the word game, first on the App Store and then on Wikipedia as a backup. The launcher takes the best match that has a picture and uses it as the cover. Found pictures are remembered in this browser, so they appear instantly next time. If nothing matches, the lookup fails, or you are offline, the card keeps its colored background and first letter. Obscure games often have no listing; for those, add img to the game's line in the EXAMPLES list.

Adding your own game files

Games saved as a single HTML file work too. Click the + Add game file tile at the end of the list and pick one or several files. Each file is read in your browser and kept there, so nothing is uploaded anywhere, and it appears in the list like any other game. Selecting it and clicking again opens it in the same disguised tab, with the same console, but with no download step because the file goes straight into the game tab. The public relay option does not matter for these.

Remove a file in Settings, under Your game files. Files live in this browser only, so a different browser or cleared browsing data starts without them. If the browser does not allow saving, a file lasts only until you close the page.

The console

The console starts off; tick it in Settings to use it. When it is on, the game tab has a small console button in its bottom-left corner. It turns red and counts errors when something goes wrong. Click it for a timestamped log of what the loader is doing, failed downloads and script errors. Problems only hides the routine messages, Copy copies the whole log so you can send it to someone, and Clear empties it. Repeated messages are folded into one line with a count.

Settings (the gear)

  • Appearance: switches this launcher between dark and light. It does not change the game tab. Your choice is remembered in this browser when the editor allows it.
  • Disguise site address: the website the tab pretends to be. Its icon is used for the tab. The preset buttons fill in both the address and a matching tab name.
  • Tab name: what the tab title says. If you leave it empty, the site's name is used.
  • Until you pick a preset or type your own, a random disguise is chosen every time a game opens. Reload the launcher to go back to random.

The four checkboxes (the console and the send-this-tab option start off; the other two start on):

  • Console: adds the console button to the game tab.
  • Public relay: allows retries through public relay services. Their operators can see which page you load, so turn it off if that bothers you. Without it, games on sites that block direct access may fail to load.
  • Ask before closing: the browser asks for confirmation before the game tab closes, so a stray click does not lose your progress.
  • Send this tab to the disguise site: a moment after the game opens, the launcher tab itself navigates to the disguise site, so the launcher's address and title are not left behind. Inside an online editor's preview, only the preview pane is sent there, not the whole browser tab.

The bottom buttons

The gear (Settings) and the megaphone (What's new, a short list of the latest features and changes) sit in the middle. The book at the right is this page.

If something goes wrong

  • Nothing opens: the editor is blocking pop-ups. Allow pop-ups for it, or open the editor's preview in its own full tab and try again. If the tab opens but shows the editor's domain in the address bar, the editor only allows a fallback method; the game still works.
  • The game page could not be fetched: the site does not let other pages read it. Turn on the public relay option, or try a different game.
  • Black screen or a game that never starts: open the console and look for red lines. A line naming a file means that download failed even after the retries. Use Copy to share the log.
